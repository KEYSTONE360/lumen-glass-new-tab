# Lumen Glass New Tab

고급 리퀴드 글라스 스타일의 Chrome 새 탭 확장 프로그램입니다. 검색, 북마크, 자주 방문한 사이트를 제공합니다. Google 검색·이미지·Drive·Classroom을 포함한 `*.google.com` 서비스에도 유리 스타일을 적용하며 우측 하단 **◐ 글라스** 버튼에서 투명도·콘트라스트·색조·흐름·굴절을 조정할 수 있습니다. 배경 액체는 서로 밀어내고 화면 가장자리에서 반사되며, 포인터를 따라 흐르고 클릭 충격에 반응합니다.

첨부 레퍼런스에서 파생한 전용 16:9 배경에는 스프링–댐퍼 기반 포인터 추종, 관성 감쇠, 국소 굴절, 이동 후류, 클릭 파동을 계산하는 WebGL 물리 셰이더가 적용됩니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 우측 상단의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더를 선택합니다.

Chrome의 주소창과 북마크 바는 브라우저 영역이므로 확장 프로그램이 변경하지 않으며, 그대로 유지됩니다.
