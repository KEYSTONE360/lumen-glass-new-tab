# Lumen Glass for Zen

Zen Browser와 Firefox용 리퀴드 글라스 새 탭 확장 프로그램입니다. 검색, 북마크, 자주 방문한 사이트를 제공하며 Zen의 사이드바·탭 UI는 변경하지 않습니다. Google 홈·첫 검색·일반 검색 결과·이미지 검색에만 글라스를 적용하고, YouTube에는 영상 동기화 주변광을 제공합니다.

첨부 레퍼런스에서 파생한 전용 16:9 배경에는 스프링–댐퍼 기반 포인터 추종, 관성 감쇠, 국소 굴절, 이동 후류, 클릭 파동을 계산하는 WebGL 물리 셰이더가 적용됩니다.

설정의 **배경화면 → 이미지 선택**에서 PNG·JPG·WebP·AVIF 이미지를 지정할 수 있습니다. 이미지는 최대 2560×1440으로 최적화되어 브라우저 로컬 저장소에만 보관되며, 새 탭과 Google 홈·검색 결과·이미지 검색의 정적 배경 및 물리 캔버스에 함께 적용됩니다. **기본 배경** 버튼으로 모든 화면을 동시에 복원할 수 있습니다.

설정 패널에서는 유리 투명도·블러·채도·콘트라스트·색조뿐 아니라 테두리, 모서리 곡률, 그림자, 외곽 발광, 버튼 투명도, 버튼 발광, 포인터 반사, 액체광, 필름 입자, 배경 암도까지 각각 독립적으로 조절하고 저장할 수 있습니다.

Google 자동완성 패널은 검색 폼 내부에서만 스타일링하며 상단 검색 탭과 결과보다 높은 독립 스택에 배치되어 텍스트나 클릭 영역이 겹치지 않습니다.

## YouTube 주변광

- 공개 MIT 프로젝트 `WesselKroos/youtube-ambilight`의 projector 구조를 참고해 독립 구현한 방향별 주변광 렌더러입니다.
- 영상 프레임의 상·우·하·좌 가장자리를 네 개의 독립 캔버스로 샘플링하며 `requestVideoFrameCallback`으로 영상과 동기화합니다.
- 확산 거리·블러·edge size·fade start·밝기·콘트라스트·채도·방향별 세기·깜빡임 감소·FPS·내부 해상도를 조절할 수 있습니다.
- 주변광 레이어는 모든 메뉴·추천 영상·검색·플레이어 컨트롤보다 뒤에 있고 입력을 받지 않아 YouTube 기본 기능을 방해하지 않습니다.
- YouTube 페이지 배경을 투명화하지 않으므로 추천 목록·영상 정보·댓글·헤더는 원본 CSS를 그대로 유지합니다.
- 주변광은 플레이어 컨테이너의 0번 레이어, 실제 영상과 컨트롤은 1번 레이어로 분리해 빛이 가려지거나 조작 UI 위를 덮지 않습니다.
- Shorts에서는 현재 활성화된 세로 영상만 추적하며 스와이프할 때마다 광원을 다시 연결합니다. 우측 Shorts 액션 버튼을 피하기 위해 주변광 설정은 좌측 하단으로 이동합니다.

렌더링 구조 참고: [Ambient light for YouTube™](https://chromewebstore.google.com/detail/ambient-light-for-youtube/paponcgjfojgemddooebbgniglhkajkj), [WesselKroos/youtube-ambilight](https://github.com/WesselKroos/youtube-ambilight) (MIT). 소스 코드를 복제하지 않고 방향별 projector와 영상 프레임 동기화 개념을 이 확장 구조에 맞춰 새로 구현했습니다.
- YouTube 영상 페이지의 **◐ 주변광** 버튼에서 확산 거리·블러·가장자리 샘플·감쇠·색상·방향·품질을 조절합니다. 버튼이 가려진 경우 `Alt + Shift + L`로 패널을 열거나 닫을 수 있습니다.
- `Shift`를 누른 채 **◐ 주변광**을 클릭하면 효과를 즉시 켜거나 끌 수 있습니다.

## 설치

### 개발·테스트 설치

1. Zen에서 `about:debugging#/runtime/this-firefox`를 엽니다.
2. **임시 부가 기능 로드**를 선택합니다.
3. 이 폴더의 `manifest.json` 또는 배포된 `.xpi` 파일을 선택합니다.
4. 새 탭 변경 권한이 표시되면 허용합니다.

임시 설치는 Zen을 종료하면 해제될 수 있습니다. 영구 설치에는 Mozilla 서명을 받은 XPI 또는 개발자 정책이 필요합니다.

Zen의 사이드바, 주소창, 탭 바는 브라우저 영역이므로 확장 프로그램이 변경하지 않으며 그대로 유지됩니다. 이 확장 프로그램은 외부 서버로 데이터를 전송하지 않습니다.
